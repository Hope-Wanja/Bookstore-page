# XYZ Bookstore Page

A simple, clean, and responsive front-end webpage for **XYZ Bookstore**, featuring a catalog of featured books and interactive shopping controls.


## Features

* **Book Catalog Showcase:** Displays featured titles such as *"Sally's SciFi Adventure"* and *"Dave's Cooking Adventure"* in a clean card layout.
* **Interactive Elements:** Includes "Buy Now" buttons for individual books, as well as "View Cart" and "Checkout" action buttons.
* **Semantic HTML5 Structure:** Built with clean, accessible markup ready for styling and JavaScript integration.
